# ArtGameCollab2.mds

AI docs and memory for the Unity game repo
[christopherlcollins/ArtGameCollab2](https://github.com/christopherlcollins/ArtGameCollab2).
The game repo stays clean: only game files go there.

- `CLAUDE.md`: rules Claude follows every session
- `docs/`: project notes Claude keeps up to date
- `setup/cloud-setup.sh`: setup script for the Claude Code cloud environment,
  so every session loads these rules automatically
